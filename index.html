Política de Privacidad

Última actualización: 28 de mayo de 2026

1. Información general

Esta aplicación, Analyzer Claude, es una herramienta de uso personal desarrollada para gestionar y analizar anuncios publicitarios a través de la API de Marketing de Meta (Facebook/Instagram).

2. Datos que se acceden

La aplicación accede a datos de cuentas publicitarias propias a través de la API de Marketing de Meta, incluyendo: campañas, conjuntos de anuncios, anuncios y métricas de rendimiento. No se recopilan, almacenan ni comparten datos de terceros.

3. Uso de los datos

Los datos obtenidos a través de la API se usan exclusivamente para análisis personal y gestión de campañas publicitarias propias. No se venden, comparten ni transmiten a ningún tercero.

4. Almacenamiento de datos

Esta aplicación no almacena datos de usuarios ni información personal en servidores externos. Toda la información se procesa localmente o a través de herramientas de IA de uso personal.

5. Acceso de terceros

Esta aplicación no comparte ningún dato con terceros. El único acceso externo es la API oficial de Meta, utilizada para obtener y gestionar los datos propios del anunciante.

6. Contacto

Si tienes alguna pregunta sobre esta política de privacidad, puedes contactar al desarrollador directamente.
